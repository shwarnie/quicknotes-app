# QuickNotes

QuickNotes is a simple web-based note-taking application that allows users to create, organize, search, and delete notes. Notes can be categorized as Personal, Work, or Study and are saved in the browser using localStorage.

## Features

* Add notes with a category
* Categories: Personal, Work, and Study
* Search notes by text
* Delete individual notes
* Clear all notes with confirmation
* Notes are saved using localStorage
* Displays the total number of notes
* Responsive design for smaller screens
* Form validation for empty notes and notes longer than 200 characters

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shwarnie/quicknotes-app.git
   ```

2. Open the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open `index.html` in a web browser.

No additional dependencies or installation are required.
